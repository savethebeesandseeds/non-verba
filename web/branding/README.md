# Branding artwork

`base_logos.png` is the original 24-design reference sheet and is preserved unchanged.

`individual/` contains 24 regenerated, standalone 1254 × 1254 PNG characters with transparent RGBA backgrounds and no lettering or numbered labels. Filenames retain the reference sheet's numbering and plant names. Decorative book symbols are part of the artwork.

The characters were regenerated with the built-in ImageGen tool, then visually inspected and checked for real alpha transparency. Native generated pixels are preserved; these are reinterpretations of the reference, not pixel-exact crops.

Exact prompts and generation details are recorded in [individual/generation.json](individual/generation.json).

`individual-transparent.zip` contains the 24 PNG files for convenient transfer.
