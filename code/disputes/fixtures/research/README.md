# Synthetic dispute research inputs

`cases.json` contains nine deliberately authored toy scenarios and seven variation
recipes. They cover role/name order, paraphrase, verbosity, irrelevant prestige,
prompt injection and valid extreme profiles. These are unsigned research inputs,
not authenticated case evidence, historical observations or signed assignments.

No model-quality experiment has been run by creating these files. The status is
**NOT_RUN**. A runner must record each exact generated variant, dictionary,
profiles, specification, seed and output/failure; never retry until it obtains a
preferred answer. Role/name-order changes must preserve actual contractual roles.

Expected statements concern explicit toy facts and contractual invariants only.
There are no target fair payments, winner labels, trust scores or discretionary
fairness ground truths. A structural test pass or a model agreeing with a toy fact
does not establish reasoning competence, fairness or resistance to manipulation.

These scenarios may be inserted as party-authored synthetic statements in a
separately signed test case. That requires real test signatures and exact retained
bytes; this file alone does not claim those signatures exist. Existing financial
regressions use the retained signed Assignment fixtures and unchanged verifier.
