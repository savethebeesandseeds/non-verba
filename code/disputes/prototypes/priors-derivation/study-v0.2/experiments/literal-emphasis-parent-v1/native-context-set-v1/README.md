# Native declared context nodes — PROTOTYPE / UNADOPTED

This isolated experiment encodes each supplied declared-context-set node separately
under the unchanged full native encoder. It changes no production representation,
extractor, frozen method, recipe, cache or accepted runtime brand. Manual witness
selection is exposed and not a general context-selection algorithm.

`prepareDeclaredNativeNodes({contextSet,declaration,raw,normalizedText,envelope,
methodPins,counter,limits?})` returns immutable `{artifact,metadata}`.
`declaration` contains `{source,focal,attachments}` in the existing context-set
schema. `methodPins` contains `tracer_source_sha256` and
`collector_source_sha256`. The supplied counter has `{policy,policy_sha256,
tokenCount}`; its whole policy canonical SHA must match. The module does not open
or authorize any counter, model, file or network resource.

The existing `verifyDeclaredContextSet` verifies literal ranges and declarations.
One `createNativeDecorationView` authenticates raw/normalized/native seals and
expected method pins, then supplies unchanged `input()` encodings. Caller ROOT
custody must authenticate the source epoch, cache/envelope receipts and annotation
references; consistent hashes alone do not establish source authenticity or reading.

The source pins and copied origins are explicit in `ORIGINS`. Only the bounded v5
planner core from `lib/embedding.mjs` lines64–118 is adapted: node text and a private
range encoder replace the production WeakMap brand; complete work is exposed on
every success. The original file SHA is
`d9629fd6df2e5250ad2e4efcab57dbc8f35c0bb559b4479aee25d586527d5340`.
The unchanged native encoder file SHA is
`a857d39a2da390175a1f817b4d2704ed1adbacff84ba6a27fefff7aee70f77fd`.
Outer execution must verify those actual import/source pins. `POLICY_SHA256`
identifies this distinct experimental bridge; it grants no production cache identity.

Every node keeps its declaration, exact text/hash, annotation ref, source identity,
native-envelope/method/encoder/counter policy bindings and individual window plan.
Local UTF16 window bounds are translated once by adding that node's original start.
Each node includes its own terminal zero events; overlapping or adjacent nodes may
repeat source and events. Roles are metadata, never input prefixes. Nodes are not
joined, sorted, merged, promoted to headings, substituted for the focal, assigned
invented parents, pooled or embedded. Window weights apply within each node only;
there is no global unique-source or token-economy claim.

Defaults are 256 tokens, 16-word fast-path overlap, v5's explicit nonoverlapping
all-language fallback, 20,000 encode probes/callback requests and 8,192 windows per
node, 2,097,152 source UTF16 units and 262,144 encoded UTF16 units per probe.
Limits additionally cap supplied JSON at32MiB, accepted node JSON at2MiB, complete
artifact plus metadata at32MiB, nodes at33 and total callback requests at60,000.
Limits can only be lowered. The supplied context set retains its original262KiB
bound. An oversized/failed node has no accepted windows; its full supplied bounded
declaration and spent work remain in a HELD record. The accepted-node output cap
does not purport to shrink that bounded failure declaration. An overall output/input
bound throws without returning a clipped or partially accepted artifact. A fresh
real scope must preflight exact input bytes before opening; these caps are not a
promise that either actual case fits.

`verifyDeclaredNativeNodes({artifact,...sameSourceInputs,counter_policy})` independently
re-encodes each retained window and verifies literal/native ranges, geometry,
per-node weights, terminal ownership, identities and structural bounds. It calls
neither the creator, planner search nor a counter. **Token counts remain supplied
callback declarations, not independently verified executions.** A later actual
entry must independently recount every final encoded string under its pinned
counter and work ledger before claiming measured readback. `execution_attested`
and `token_counts_independently_verified` stay false. The supplied executable
callback is not sandboxed. `summarizeDeclaredNativeNodes(artifact)` reports bounded
counts/digests, not a validity or quality judgment.

The focused SOURCE_FREE controls compare real synthetic collector focal plans
against production v5, including exact native bytes/hash, `source_ranges`, fixed
policy fields, UTF16 geometry, weights and zero-event ownership. Other controls
cover outside-parent/overlapping declarations, word/CJK paths,296-style and
nonmonotone repairs, projection limits, retained failures/work, immutable inputs,
resource bounds and independent tamper rejection. The original296 corpus case is
not an input. Run the test only in the managed container; ROOT may transfer just
these files and resolve their explicit relative imports to frozen B3:

`node --test native-nodes.test.mjs`
