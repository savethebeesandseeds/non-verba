# Boundary source replay — PROTOTYPE / UNADOPTED

This in-memory kernel replays the fixed0055→0047 source-only comparison through
the existing nine-tag baseline and frozen list-governor boundary variant. ROOT
owns a separate prospective entry, custody validator, budget, private permit,
no-follow reads and external completion. This module opens no files, mints no
capabilities, invokes no tokenizers/models, and grants no source reading or
quality authority. The0048 available resource failure remains unchanged.

`prepareBoundaryReplay({binding,row,record,currentCache,sourceProof,freshGuard,
rawBytes,normalizedBytes,baselineNativeBytes,custody})` requires the exact
original cache contract/source and fixed canonical cache/storage hashes. ROOT
reads that cache and its receipt under the new permit; no original V4 native
payload is needed. The three source documents are derived from the prior Q12
packet. `custody` contains the prior completion/manifest/descriptor refs, full
raw/normalized/native document refs and parsed descriptor. Other policy fields
are tolerated. ROOT verifies the complete prior custody graph and encoded
document hashes; this pure kernel verifies decoded hashes, fixed paths,
descriptor identity, current874 and the exact complete100-row/29-CID guard.

Extraction and selection parameters remain those of the original current874
proof; selection is explicitly not recomputed. Fixed source-code method hashes
identify the baseline, variant and common tracer. ROOT must bind those actual
module files in its reviewed source epoch before import. The baseline must
reproduce the prior nine-tag envelope byte-for-byte, match the current cache in
all existing non-native bridge fields, and retain the original focal/parent
geometry. The full baseline is serialized and discarded before extracting the
variant. The variant must preserve normalized literals, the full native trace,
origin segments and unknowns under its distinct collector identity. Its parent
and unit geometry may change and is reported without forcing old IDs or a
zero non-native/selection difference.

The return is `{baselineBytes,variantBytes,summary,inputDecodedBytes}`. Both
buffers contain compact, unabridged JSON artifacts with the full raw source,
extractor result, native envelope, original geometry, record, proof and custody.
ROOT retains them losslessly as gzip. The summary contains numeric intervals,
counts, hashes, booleans and static status codes, including overlapping variant
parents, original focal coverage/gaps and closure hypotheses. It contains no
heading labels, warning messages or source words. Input includes decoded cache
plus all three derived source documents within32MiB; combined decoded baseline
and variant artifacts plus summary must also fit32MiB per case. ROOT additionally
enforces encoded, physical-output and cumulative resource bounds. No truncated
or partial artifact is accepted.

`measureReplayInvariants(...)` is the pure facts helper used by internally
authored SOURCE_FREE controls. The unstyled-number-before-B/U-title control
intentionally demonstrates a gap beyond the earlier11 boundary controls:
styling the title without styling its preceding number can leave the frozen
predicate inactive. Actual replay may therefore report zero closures. This
prototype exposes that result and does not modify the frozen rule or infer the
active0055 branch from source appearance alone. Focal packing remains unchanged.
