# Literal Emphasis and Parent Stream — PROTOTYPE / UNADOPTED

This source-free experiment is isolated from the current Priors Derivation Lab
method. It neither imports study observations nor changes production source,
recipes, caches, quality gates, census jobs or actual review journals. Its only
runtime dependencies are the existing pinned parser and tokenizer-only APIs in
the managed Linux container. It performs no model inference or factual-answer
evaluation and makes no priors claim.

`source-decoration.prototype.mjs` is a minimal explicit fork of the frozen
tracer. `upstream/` retains both original source files byte for byte;
`fork-patches.json` reconstructs both forks and documents import routing. The
fork traces distinct literal `strike/s/del/ins/u/b/strong/i/em` tags. Original
`font`, `font-weight` and `font-style` declarations are relevant literal evidence
with unverified effects. Native tags and CSS are never interpreted as a clean
legal version or computed appearance.

`finite-codec.mjs` deliberately reduces evidence for model input. Literal text
roundtrips; native order/multiplicity, CSS values/cascade, full joint/zero origin
witnesses and coordinates do not. The complete treatment is in
`omitted-fields.json`. Nine tag names do not resolve CSS materiality. Any material
omission rejects this candidate. Exact rich source evidence and a reversible
text stream are different claims.

`parent-stream.mjs` creates exact source descriptors for three unit-only
ablations and one full-stored-parent context variant. Full-parent availability
does not establish governing dependency completeness. No heading/navigation,
summary, relevance ranking or author answer is inserted. Identical parent input
for several focal units is disclosed; pooling, dilution and dependency
understanding remain unevaluated.

`window-planner.mjs` selects unencoded word boundaries and then Unicode codepoint
boundaries when necessary, re-encodes complete finite markers for each window,
and recounts the full input against the selected tokenizer. Overlap is zero.
It need not find the largest possible window. Resource exhaustion or a minimum
codepoint overflow rejects the complete input; no successful prefix or plaintext
fallback is returned. `tokenizer-controls.mjs` tests both pinned tokenizers,
including every valid finite mask and a 1,107,802-character synthetic parent.
That stress has its own 512-call/model initial budget and may fail explicitly.
This is not a universal 256-token or full-parent feasibility guarantee.

The P1/P2 engineering revision copies private encoding state and returns
separate recursively frozen diagnostics, bindings and descriptors. Caller-owned
evidence, qualification and parent/unit metadata cannot change later encoding
or its identities. Metadata is plain data (bounded at100,000 containers and
256 nesting levels); executable properties, cycles and mutable exotic
containers are rejected. Planner options are checked before tokenization and
cannot exceed the existing protocol ceilings; smaller budgets remain allowed.
Frozen d77ed source/results and the independent review remain historical
artifacts, including the initial CRLF wrapper failure.
