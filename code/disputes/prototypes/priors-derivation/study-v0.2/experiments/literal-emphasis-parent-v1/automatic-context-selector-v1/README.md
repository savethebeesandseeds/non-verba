# Automatic literal context selector — PROTOTYPE / UNADOPTED

`selector.mjs` is one pure bounded experiment after unit selection. It changes no
frozen extractor, source194, parent, unit, audit, production model input or gate.
It accepts the complete normalized source, an exact focal range, existing source
navigation anchors and governor frames. There is no manual witness-catalog input.
Source custody must be authenticated by an outer separately admitted execution;
consistent supplied metadata alone grants no source authenticity or legal meaning.

The selector derives provisional intervals from numbered-caption metadata, ending
at the next compatible literal marker of the same numeral family and same or
shallower dotted depth, or retained
source end. All intervals touched by the focal, including heading-only tails, are
separate context nodes. Intersecting existing governor prefixes remain separate.
They are conservative source evidence, not verified semantic governors. Typed
Roman markers are supported; an untyped Roman marker requires another canonical
Roman numeral differing by one. An isolated C/D/I can be a letter, so ambiguity
is retained HELD rather than silently becoming a Roman boundary.
Eligible kind/source-kind pairs are the six numbered/caption/document-title
pairs observed in the pinned metadata probe. Other numeric navigation evidence
is excluded from interval construction and explicitly retained HELD. This narrow
allowlist does not turn known page/address/nonheading labels into captions.
Stopping at a shallower dotted marker limits child-range growth; it verifies no
legal parent/child hierarchy or completeness.

It scans the selected intervals, governor prefixes and focal for explicit
Section, Paragraph, Article, Clause and section-sign references. Numeric/dotted
or canonical Roman identifiers, finite groups and bounded integer ranges resolve
only to unique supplied literal candidates. Untyped labels are provisional
aliases. Missing/duplicate/ambiguous candidates, unsupported suffixes, exhausted
reference depth or resource bounds remain explicit unresolved/HELD outcomes.
Cycles terminate through already included targets. At the two-hop limit, scanned
unselected references remain reported. No implicit definition, external exhibit,
unrecognized reference grammar, semantic completeness or model effect is inferred.
Literal Exhibit/Schedule/Appendix/Annex/Attachment/Rider references receive
explicit unsupported-or-external rows with source ranges/hashes and a HELD
reason. Supported literal-reference selection is not full dependency closure or
context adequacy; unavailable exhibits are never silently treated as resolved.

The output contains exact source ranges/hashes and selection metadata, without
joining source text or promoting a caption into the model input. Defaults bound
attachments to 32, attached characters to 65,536, reference occurrences to 512 and
reference depth to two. Every option can only lower its fixed ceiling. Native
window planning, tokenizer feasibility and fresh source reading remain separate.
The known native fallback's possibility of splitting a word remains unresolved.

The focused tests use internally authored source/navigation metadata; they do not
open an actual corpus, tokenizer, model asset or inference session. Run them only
in managed Debian with a narrow source copy, reusing an existing source snapshot:

`node --test selector.test.mjs`
