Nested blocks, line breaks and other inline tags do not supply this observation.
The observation must equal the exact title already emitted by the unchanged
numbered-heading/inline-title/navigation grammar. It cannot create a heading,
navigation entry, normalized separator or source character.

Both the governing caption and candidate must have that private literal-tag
evidence. V2 also retains V1's initial/whole emphasized-caption route when it has
actual tag evidence. V1's navigation seed name could also cover centered plain
text or CSS styling, so V2 is deliberately stricter on those inputs. It does not
infer computed style or accept generic layout-caption evidence.
