## Executable fictional interfaces

`admitFictionalMetadata({phase,input_root,output_root,bindings,roster_ref,source_epoch_sha256,actual_authority:false})` detaches immutable data and returns a private permit. The phase must be `METADATA_SELECTION_ONLY`; only real no-follow sibling fixture roots are accepted. Actual RUN cannot be a fixture root. Generic parent reads accept only the exact four bound manifest/fresh/development/roster references.

Admission rejects any bindings key beyond exactly `manifest`, `fresh`, `development`, and validates their three references plus the roster reference and epoch before filesystem access. The parent reader independently enumerates those three roles plus roster; additional raw/cache/native references cannot broaden its allowlist before preflight or after INIT. The fixture module exposes only `metadataFixture`; its generic JSON/byte writer helpers are private and used only with that factory's minted UUID root and generated fixed names.

`preflightFictionalMetadata(permit)` reads only those metadata inputs. It authenticates current source binding, fresh100→29, complete ordered development200 and mandatory45 membership/order. It returns a private-branded immutable scope with a hash, legacy guard and complete fresh-ID wrapper. No excerpts, coder fields, cache/native bodies or raw text are returned. A protected mandatory row produces HELD and prevents INIT. The complete ordered200 IDs are derived once here, never fabricated as a configuration default.

`createFictionalHandshake(permit,scope)` requires the actual private preflight object. HELLO→REGISTERED→READY yields a private INIT bound to source epoch, preflight digest, original200/mandatory45 and0 tokenizer calls/empty streams. Its PID/birth declarations are synthetic data only. It does not probe, spawn, signal or prove ownership.

`readCache(input_root,ref,{permit,budget})` requires that INIT, exact current manifest cache reference and a nonprotected development CID before file access. It verifies private receipt, encoded/decoded bytes, strict UTF8/JSON, canonical cache serialization, current source and native lineage. `hydrateNative(...)` additionally requires that bound cache first, exact manifest native declaration and bounded full-envelope integrity. Original `raw_path` and normalized path values remain binding metadata; there is no raw/normalized-file read function. The copied projector retains all record/status/native/geometry authentication before marking an unavailable anchor ineligible. Existing native/cache content is not manual reading or a new extraction.

`runFictionalMetadataDriver(init)` reuses that projector and fixed selector. Missing, protected, unavailable mandatory or quota gaps hold the draw with no refill. All original200 outcomes remain partitioned; the nominal selected denominator stays69. Cache/metadata failures remain explicit original failures. `startFictionalMetadataSelection(context)` runs this in-process fixture path and writes three parent outputs before INIT plus three worker outputs after INIT. It returns records to fictional controls only; it provides no actual guardian proof.

Output names are exactly `parent-preflight.json`, `ordered-development200-ids.json`, `complete-fresh-guard.json`, `metadata-projection.json`, `ordered69-freeze.json`, `summary.json`. Writes resolve only against output_root, require private scope, are exclusive/fsynced/read back, and have an8MiB metadata ceiling inside128MiB. No input is copied or symlinked into outputs.
