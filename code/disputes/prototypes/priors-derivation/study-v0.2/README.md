## Running the study

Follow the [container plan](../../../../../docs/development/CONTAINER_PLAN.md) and
[snapshot guide](../../../../../docs/development/CONTAINER_MIGRATION.md). The wrapper
uses the existing verified container and pinned dependencies, installing no
Windows toolchain and making no container lifecycle changes. From the public
checkout:

```powershell
$study = './code/disputes/prototypes/priors-derivation/study-v0.2/Invoke-Study.ps1'
& $study -Action Test -ModelSmoke
& $study -Action Init -RunName new-study-name
& $study -Action Acquire -RunName new-study-name -Limit 1000
& $study -Action Extract -RunName new-study-name -Limit 1000
& $study -Action Audit -RunName new-study-name -Manifest processing/SOURCE/calibration-1000/extraction-manifest.json
& $study -Action Prepare -RunName new-study-name -Manifest processing/SOURCE/calibration-1000/extraction-manifest.json
& $study -Action Embed -RunName new-study-name -Manifest admission/STAGE/manifest.json
& $study -Action Discover -RunName new-study-name -Manifest embeddings/STAGE/manifest.json
& $study -Action Verify -RunName new-study-name -Embeddings embeddings/STAGE/manifest.json -Geometry geometry/STAGE/manifest.json
```

Replace `SOURCE` and `STAGE` with the exact manifest paths printed by the preceding
command. Init freezes a new run. Completed stages are immutable; resumes verify
retained bytes and identities. An interrupted partial init needs a new named run,
while acquisition and processing checkpoints resume the same frozen selection.
The whole-study source snapshot and individual stage source hashes are recorded
when available. An absent snapshot environment value remains absent.

After the calibration gate passes, acquire the same discovery prefix with
`-Limit 10000` and extract with `-FullDiscovery -Limit 10000`. Preserve cumulative
1,000/3,000/6,000/10,000 checkpoints. The currently executing run is
`20261013-study-15000`; inspect its actual progress before resuming a worker.
One acquisition writer is enforced, and a timeout does not prove that worker
has stopped. Respect recorded throttling pauses rather than restarting around them.

The read-only paginated review uses the existing container port 4173 and its
documented loopback mapping. Preserve another service if the port is occupied.
Use the exact admission and geometry manifest paths with `-Action Serve`.
The local review entry is `noindex`, keeps scripts strict, and permits only the
selector's narrow style-element exception. Corpus payload is fetched in bounded
pages instead of importing all clauses or vectors into a browser.

Resource ceilings are 4 MiB per raw contract, 8 GiB raw bytes, 24 GiB total run
storage and a 6 GiB processing-memory target. Exhaustion pauses work while
preserving existing objects. No ceiling increase or data deletion is automatic.
